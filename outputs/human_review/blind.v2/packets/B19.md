#### `p:3` kind=heading heading_level=2 depth=0

什么是 HTML？

#### `p:4` kind=paragraph depth=0

HTML（HyperText Markup Language，超文本标记语言）是一种标记语言，它告诉 Web 浏览器如何组织你访问的网页。它可以像 Web 开发者希望的那样复杂或简单。HTML 由一系列的元素组成，你使用这些元素来包围、包装或标记内容的不同部分，使其以某种方式显示或运作。闭合的标签可以使内容成为一个连接到其他页面的超链接、将文字变为斜体等等。例如，考虑下面这行文本：

#### `p:5` kind=code depth=0

My cat is very grumpy


#### `p:6` kind=paragraph depth=0

如果我们想让这段文本独立成段，我们可以用段落（<p>）元素来包裹它：

#### `p:7` kind=code depth=0

<p>My cat is very grumpy</p>


#### `p:8` kind=paragraph depth=0

HTML 存在于扩展名为 .html 的文本文件中，这种文件被称为 HTML 文档，或简称文档。在我们之前谈论网页的地方，一个 HTML 文档包含了网页的内容并指定了其结构。

#### `p:9` kind=paragraph depth=0

你将遇到的最常见的 HTML 文件是 index.html，它通常用于包含网站主页的内容。同样常见的是看到带有各自 index.html 的子文件夹，因此一个网站可以在不同的位置有多个索引文件。

#### `p:10` kind=paragraph depth=0

备注：HTML 中的标签不区分大小写。这意味着它们可以用大写或小写书写。例如，<title> 标签可以写成 <title>、<TITLE>、<Title>、<TiTlE> 等，并且都能正常工作。但是，为了保持一致性和可读性，最佳实践是所有标签都用小写书写。

#### `p:29` kind=paragraph depth=0

布尔属性

#### `p:64` kind=paragraph depth=0

有时你会看到没有值的属性。这是完全可以接受的。这些被称为布尔属性。当一个布尔属性没有值，或有任何值（甚至像 "false"）时，该布尔属性总是被设置为 true。否则，如果该属性没有写在 HTML 标签中，该属性就被设置为 false。规范要求该属性的值要么是空字符串（包括属性没有明确指定值时），要么与属性的名称相同，但其他值的作用也一样。例如，考虑 disabled 属性，你可以把它赋给表单输入元素。（你可以用它来禁用表单输入元素，这样用户就不能输入内容了。被禁用的元素通常呈现为灰色。）例如：

剖析 HTML 文档

#### `p:88` kind=paragraph depth=0

单个 HTML 元素本身并不是很有用。接下来，让我们看看单个元素如何组合成一个完整的 HTML 页面：

#### `p:89` kind=code depth=0

<html lang="zh-CN">
  <head>
    <meta charset="utf-8" />
    <title>我的测试页面</title>
  </head>
  <body>
    <p>这是我的页面</p>
  </body>
</html>


#### `p:90` kind=paragraph depth=0

这里我们有：

#### `p:91` kind=list_item list_type=ol depth=0 ordinal=1

<!doctype html>：文档类型声明（doctype）。在 HTML 早期（1991-1992 年），doctype 旨在作为一套规则的链接，HTML 页面必须遵循这些规则才能被认为是好的 HTML。过去的 doctype 看起来像这样：

#### `p:92` kind=list_item_continuation list_type=ol depth=0 ordinal=1

html

#### `p:93` kind=code list_type=ol depth=0 ordinal=1

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">


#### `p:94` kind=list_item_continuation list_type=ol depth=0 ordinal=1

最近，doctype 成为了一个历史遗留物，为了让其他一切正常工作而必须包含它。<!doctype html> 是算作有效 doctype 的最短字符序列。你只需要知道这些！

#### `p:95` kind=list_item list_type=ol depth=0 ordinal=2

<html></html>：<html> 元素。这个元素包裹了页面上的所有内容。它有时被称为根元素。

#### `p:96` kind=list_item list_type=ol depth=0 ordinal=3

<head></head>：<head> 元素。这个元素充当一个容器，用于存放你想包含在 HTML 页面中但不向页面浏览者显示的内容。这包括会出现在搜索结果中的关键字和页面描述、用于样式化内容的 CSS、字符集声明等等。你将在本系列的下一篇文章中学到更多相关内容。

#### `p:97` kind=list_item list_type=ol depth=0 ordinal=4

<meta charset="utf-8">：<meta> 元素。这个元素代表了不能由其他 HTML 元相关元素（如 <base>、<link>、<script>、<style> 或 <title>）表示的元数据。charset 属性将你的文档的字符编码指定为 UTF-8，它包含了绝大多数人类书面语言的字符。通过这个设置，页面现在可以处理它可能包含的任何文本内容。没有理由不设置它，而且它可以帮助避免以后的一些问题。

#### `p:98` kind=list_item list_type=ol depth=0 ordinal=5

<title></title>：<title> 元素。它设置了页面的标题，这个标题会出现在加载该页面的浏览器标签页中。当页面被收藏为书签时，页面标题也用于描述该页面。

#### `p:99` kind=list_item list_type=ol depth=0 ordinal=6

<body></body>：<body> 元素。它包含了在页面上显示的所有内容，包括文本、图像、视频、游戏、可播放的音轨或其他任何东西。

字符引用：在 HTML 中包含特殊字符

#### `p:127` kind=paragraph depth=0

在 HTML 中，字符 <、>、"、' 和 & 是特殊字符。它们是 HTML 语法本身的一部分。那么你如何在文本中包含这些特殊字符之一呢？例如，如果你想使用一个与号或小于号，而不是让它被解释为代码。

什么是 HTML？

#### `g:3` kind=paragraph depth=0

HTML（HyperText Markup Language，超文本标记语言）是一种标记语言，它告诉 Web 浏览器如何组织你访问的网页。它可以像 Web 开发者希望的那样复杂或简单。HTML 由一系列的元素组成，你使用这些元素来包围、包装或标记内容的不同部分，使其以某种方式显示或运作。闭合的标签可以使内容成为一个连接到其他页面的超链接、将文字变为斜体等等。例如，考虑下面这行文本：

#### `g:6` kind=code depth=0

#### `g:7` kind=paragraph depth=0

#### `g:8` kind=paragraph depth=0

#### `g:9` kind=paragraph depth=0

备注：HTML 中的标签不区分大小写。这意味着它们可以用大写或小写书写。例如，<title> 标签可以写成 <title>、<TITLE>、<Title>、<TiTlE> 等，并且都能正常工作。但是，为了保持一致性和可读性，最佳实践是所有标签都用小写书写。

#### `g:72` kind=code depth=0

#### `g:73` kind=paragraph depth=0

如上所示，浏览器会误解标记，将 title 属性误认为三个属性：一个值为 The 的 title 属性，以及两个布尔属性 Mozilla 和 homepage。显然，这不是我们想要的！它会导致错误或意想不到的行为，正如你在下面的实时示例中看到的那样。试着将鼠标悬停在链接上查看标题文本！

#### `g:76` kind=paragraph depth=0

剖析 HTML 文档

#### `g:87` kind=paragraph depth=0

单个 HTML 元素本身并不是很有用。接下来，让我们看看单个元素如何组合成一个完整的 HTML 页面：

#### `g:88` kind=code depth=0

<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="utf-8" />
    <title>我的测试页面</title>
  </head>
  <body>
    <p>这是我的页面</p>
  </body>
</html>


#### `g:89` kind=paragraph depth=0

这里我们有：

#### `g:90` kind=list_item list_type=ol depth=0 ordinal=1

<!doctype html>：文档类型声明（doctype）。在 HTML 早期（1991-1992 年），doctype 旨在作为一套规则的链接，HTML 页面必须遵循这些规则才能被认为是好的 HTML。过去的 doctype 看起来像这样： html<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd"> 最近，doctype 成为了一个历史遗留物，为了让其他一切正常工作而必须包含它。<!doctype html> 是算作有效 doctype 的最短字符序列。你只需要知道这些！

#### `g:91` kind=list_item list_type=ol depth=0 ordinal=2

<html></html>：<html> 元素。这个元素包裹了页面上的所有内容。它有时被称为根元素。

#### `g:92` kind=list_item list_type=ol depth=0 ordinal=3

<head></head>：<head> 元素。这个元素充当一个容器，用于存放你想包含在 HTML 页面中但不向页面浏览者显示的内容。这包括会出现在搜索结果中的关键字和页面描述、用于样式化内容的 CSS、字符集声明等等。你将在本系列的下一篇文章中学到更多相关内容。

#### `g:93` kind=list_item list_type=ol depth=0 ordinal=4

<meta charset="utf-8">：<meta> 元素。这个元素代表了不能由其他 HTML 元相关元素（如 <base>、<link>、<script>、<style> 或 <title>）表示的元数据。charset 属性将你的文档的字符编码指定为 UTF-8，它包含了绝大多数人类书面语言的字符。通过这个设置，页面现在可以处理它可能包含的任何文本内容。没有理由不设置它，而且它可以帮助避免以后的一些问题。

#### `g:94` kind=list_item list_type=ol depth=0 ordinal=5

<title></title>：<title> 元素。它设置了页面的标题，这个标题会出现在加载该页面的浏览器标签页中。当页面被收藏为书签时，页面标题也用于描述该页面。

#### `g:95` kind=list_item list_type=ol depth=0 ordinal=6

<body></body>：<body> 元素。它包含了在页面上显示的所有内容，包括文本、图像、视频、游戏、可播放的音轨或其他任何东西。

#### `g:121` kind=heading heading_level=2 depth=0

字符引用：在 HTML 中包含特殊字符

#### `g:122` kind=paragraph depth=0

在 HTML 中，字符 <、>、"、' 和 & 是特殊字符。它们是 HTML 语法本身的一部分。那么你如何在文本中包含这些特殊字符之一呢？例如，如果你想使用一个与号或小于号，而不是让它被解释为代码。

#### `g:123` kind=paragraph depth=0

你需要使用字符引用。这些是代表字符的特殊代码，用于在这些确切的情况下使用。每个字符引用都以一个与号（&）开始，并以一个分号（;）结束。

#### `g:124` kind=table depth=0

字面字符 | 字符引用等效项
< | &lt;
> | &gt;
" | &quot;
' | &apos;
& | &amp;

#### `g:125` kind=paragraph depth=0

字符引用的等效项可以很容易记住，因为它使用的文本可以看作是 &lt; 对应“less than（小于）”，&quot; 对应“quotation（引语）”，其他类似。要查找更多关于实体引用的信息，请参见 XML 和 HTML 字符实体引用列表（维基百科）。

#### `g:126` kind=paragraph depth=0

#### `g:127` kind=code depth=0

<p>HTML 中用 &lt;p&gt; 来定义段落元素</p>

#### `g:129` kind=paragraph depth=0

备注：你不需要为任何其他符号使用实体引用，只要你的 HTML 字符编码设置为 UTF-8，现代浏览器就能很好地处理实际的符号。

#### `g:130` kind=heading heading_level=2 depth=0

HTML 注释

#### `g:131` kind=paragraph depth=0

HTML 有一种在代码中写注释的机制。浏览器会忽略注释，实际上使用户看不到注释。注释的目的是让你在代码中包含注释，以解释你的逻辑或编码。如果你在离开很长时间后回到一个代码库，以至于你不能完全记住它，这就非常有用。同样，当不同的人在进行修改和更新时，注释也是非常宝贵的。

#### `g:132` kind=paragraph depth=0

要编写 HTML 注释，请将其包裹在特殊标记 <!-- 和 --> 中。例如：

#### `g:133` kind=code depth=0

<p>我不在注释里</p>

<!-- <p>但我在注释里</p> -->
