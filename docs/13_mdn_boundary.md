# 实操13：MDN 文档页的正文容器边界

MDN 页面使用 `main#content` 作为语义主区域，但它内部同时包含翻译横幅、右侧“本文内容”目录、正文和文章页脚。直接把 `main#content` 当正文容器会把页面结构带入结果。

本页更合适的正文候选是：

```xpath
//div[contains(concat(' ', normalize-space(@class), ' '), ' layout__body ')]
```

它对应 `layout__body reference-layout__body`，包含文章的 h2/h3、段落、列表和 HTML 代码块。需要排除的页面结构包括翻译横幅、顶部或侧边导航、右侧目录、上一页/下一页按钮、文章反馈区和页脚。

## 人工确认的口径

建议保留文章标题“HTML 基础语法”、开头介绍、正文小标题、普通段落、正文列表、HTML 代码块以及“参见”中的参考链接文字。页面中的图片只保留其相邻文字，不识别图片内容。需要你确认：

1. 开头的学习目标/前提表格是否作为正文结构纳入；
2. “参见”中的参考链接文字是否纳入正文末尾；
3. 代码块是否按 `code` 结构保留缩进与换行。

上述三项现已由用户确认保留。expected 和首次预测此前按相同推荐口径生成，本次回复未修改 expected。标题、介绍与前提/学习目标在 layout__header，正文主体在 layout__body，范围包含两部分。结果与协议差异见 14_mdn_first_validation.md。MDN 已参与修复，当前作为 development 使用。
