# P-A · 单标注者局限声明（2026-11-23）

> 本声明为永久性如实局限记录。接受单标注者制度无需新增动作；若日后需要多人 IAA，另行安排。

## 1. 制度事实

- 全部人类 gold 由**单一标注者 hqli631** 完成（P0 23 例、P2 18 例、P3 复审 10 例裁决）。
- 用户于 2026-11-22 明确豁免第二标注者（原话："不需要第二标注者了"）。
- 因此**不存在标注者间一致性（IAA /  human–human Cohen κ）**，也无法量化标注者系统偏差。

## 2. 不可混淆的指标

- 已报告的 κ（P0 全量 0.5077、P1.5 dev 0.8554、development 0.8246）均为 **judge–人类 一致率**，**不是** human–human IAA。
- P2 frozen_test v2 的 κ 因 gold 单类退化而**无信息量**（已如实声明）。
- 一致率 ≠ 准确率；judge–人类一致高不代表两者都正确（C01/C02 即人类漏检而 judge 正确）。

## 3. 对结论的影响

- gate 阈值（false_alarm≤0.15、severe_miss≤1）是对**单标注者 gold** 校准的，继承其偏差；gate FAIL/PASS 的解释须带此局限。
- 严重度锚点（major/minor/critical）的人类校准来自单一视角，A01/A05 的同型变异不一致即其体现；P-B 修订须以量级化锚点降低主观依赖。
- 所有"泛化""可信度"结论限于单标注者、小样本、dev 模板族范围。

## 4. 已应用的缓解

- 盲码 + 密封映射（blind.v2 / p2.blind.v1 / p3.blind.v1）；D1 泄漏偏差披露（标签先于泄漏填完，无回填通道）。
- 机械修复仅从标注者本人 note 按冻结锚点推导 severity（repair_human_labels.py），不读 judge/silver/映射，原文件不覆盖 + sha256 审计。
- 裁决留 adjudication_note；程序化侧核（rubrics_v2）三角佐证（post-hoc，不回传）。
- 封存 gold 不可回改；修订须预注册。

## 5. 声明

本项目当前所有人类 gold 与裁决均为单标注者产物；IAA 缺失是**已知且被接受**的局限，不假装存在多人一致性证据。任何对外表述须携带本声明。
