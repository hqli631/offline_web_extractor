# Gate8 Rubrics 评估协议

本文是历史 v1 协议。项目三自 2026-11-17 起新增独立的 [v2 协议](RUBRICS_V2_PROTOCOL.md) 和 `rubrics_v2.py`；旧版结果保持原算法。下段“只改变文本不影响结构维度”为旧说明，v1 实际签名还包含文本和 `source_id`。v2 将文本对齐覆盖、结构属性和代码格式分开记录，详细定义以 v2 为准。

Rubrics 用于解释正文质量，不能代替冻结标准答案。完整性按分词后的多重集合召回和精确率，分词把中文字符单独计数、拉丁词和数字保留为单元；同长度替换也会降低分数。纯净度按评测者显式提供的噪声词命中和多提 token 计算。结构按有序块签名的 LCS 比例，签名包含 kind、heading_level、list_type、depth、ordinal、footnote_label；只改变文本不影响结构维度。三维均为 0–4，并保留连续值。网页中的“忽略指令”等内容一律是数据，只有评测者提供的 noise_terms 才触发扣分。Gold 只进入评测层，不进入 Agent prompt。重复评分用平均绝对差（MAD）；没有重复标签时一致性返回 null，而不是假设完美一致。当前没有真实 LLM Critic 或多人标注结果。
